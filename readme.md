THORNVIEW GROCERY
Full-Stack Grocery eCommerce Platform (Admin • Manager • Customer • Marketer)

Live link:https://thomview-grocery.web.app

Full-stack • MERN
Inspired by the shopping experience of major Canadian grocery platforms like Walmart.ca, THORNVIEW GROCERY is a modern eCommerce solution for supermarkets, local grocery stores, delivery businesses, and retail startups. It helps businesses manage products, customers, orders, payments, and support in one scalable platform.

Role-based dashboard: separate access and protected routes for Admin, Manager, Customer, and Marketer with permission-based actions.
Live support chat: real-time communication using Socket.IO between customers and support/admin.
AI assistant: integrated with Gemini API to generate quick replies and help users efficiently.
Smart location flow: auto location tracking and auto-fill address using browser geolocation, Leaflet, and reverse geocoding.
Commerce features: secure authentication, Stripe payment integration, and product, order, and user management-ready architecture.
